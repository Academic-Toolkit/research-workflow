# research-presentation

研究發表階段的文件。

## Skills

| Skill | 做什麼 |
|---|---|
| `presentation-memo` | 從定稿的海報（或短講投影片）產生三份備忘稿：30 秒版、約 2 分鐘版、4–5 分鐘導覽版（含〔動作〕指示）。日文講稿每段第一次出現的漢字詞標「漢字（かな）」讀音，文末附數學記號念法表。 |

## 檢查工具

`skills/presentation-memo/scripts/script_check.py`：去掉讀音與〔動作〕後量字數、估朗讀時間（預設每分鐘 315 字）；`--plain` 輸出純口語文字，供語序盲讀。

## 不做的事

- 不設計、不修改海報本身；海報的問題列出來交給使用者決定。
- 不自動寄出或上傳講稿。
